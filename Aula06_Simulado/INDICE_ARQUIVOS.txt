ARQUIVOS CSS (Modularizados)
──────────────────────────────

reset.css (base/)
  ├─ box-sizing: border-box em tudo
  ├─ margin: 0 no body
  ├─ list-style: none em ul/ol
  └─ font: inherit em form elements

variaveis.css (base/)
  ├─ Cores: --cor-primaria, --cor-destaque, --cor-texto, --cor-fundo, etc
  ├─ Fontes: --fonte-texto, --fonte-titulo
  ├─ Espaçamentos: --espaco, --espaco-pequeno, --espaco-grande
  ├─ Raios: --raio, --raio-grande
  └─ Sombras: --sombra
  💡 TIP: Mude --cor-primaria e veja o site inteiro mudar!

tipografia.css (base/)
  ├─ body: font-family, line-height, color, background
  ├─ h1...h6: tamanhos, pesos, cores
  ├─ p: espaçamento
  ├─ a: cores, estados (hover, focus, visited)
  └─ figure/figcaption

cabecalho.css (layout/)
  ├─ .cabecalho: display flex, justify-content space-between
  ├─ .logo: estilização
  ├─ .menu: display flex com gap
  └─ Links: hover com border-bottom, focus com outline

secoes.css (layout/)
  ├─ main: padding, max-width
  ├─ section: background, border-radius, box-shadow
  ├─ .sobre__conteudo: display flex (imagem + texto)
  ├─ .galeria: display grid com auto-fit e minmax
  ├─ .contato: gradiente de fundo
  └─ .rodape: cor primária, text-align center

responsividade.css (layout/)
  ├─ @media (min-width: 768px): aumenta padding, redimensiona fonte
  ├─ @media (min-width: 1024px): mais ajustes
  └─ Mobile-first: estilos base para mobile, @media acrescenta

botao.css (componentes/)
  ├─ .botao: display inline-block, padding, background, border-radius
  ├─ .botao:hover: transform translateY, box-shadow
  ├─ .botao:focus-visible: outline 2px
  ├─ .botao--destaque: cor laranja, width 100%
  └─ .botao--secundario: background transparent, border

formulario.css (componentes/)
  ├─ fieldset + legend: borda, padding, background
  ├─ label: display block, font-weight
  ├─ input[type="text|email|tel"]: width 100%, padding, border
  ├─ textarea: resize vertical, min-height
  ├─ input:focus: outline none, border-color primária, box-shadow
  ├─ input:invalid: border vermelha
  └─ input:valid: border verde

card.css (componentes/)
  ├─ .card: display flex, flex-direction column, padding, border
  ├─ .card h3: cor primária
  ├─ .card p: flex: 1 (cresce)
  ├─ .card .botao: margin-top auto (fica na base)
  └─ .card:hover: transform, sombra, border-color

main.css (raiz do css/)
  └─ Contém apenas @import de todos os módulos em ordem
