2. HTML SEMÂNTICO (Aulas 02-03)
================================================================================

[ ] DOCTYPE está na primeira linha
[ ] <html lang="pt-BR">
[ ] <meta charset="UTF-8">
[ ] <meta name="viewport" content="width=device-width, initial-scale=1.0">

[ ] <header> com:
    [ ] <h1> (um só em toda a página)
    [ ] <nav> com <ul> e <li>

[ ] <main> contendo:
    [ ] <section id="inicio"> (sobre)
    [ ] <section id="projetos"> (projetos)
    [ ] <section id="contato"> (contato)

[ ] <footer> com:
    [ ] <address> com email ou telefone

[ ] Nenhuma <div> sem justificativa
    (As que existem têm motivo, ex: .sobre__conteudo para flex)

[ ] Validação W3C: ZERO ERROS
    (Já testou em validator.w3.org? Sim ☐ Não ☐)

5. CSS EXTERNO E MODULAR (Aula 06)
================================================================================

[ ] Arquivo css/main.css existe
    [ ] E tem @import de todos os módulos
    [ ] Na ordem: base → layout → componentes → responsividade

[ ] Arquivo css/base/variaveis.css com:
    [ ] --cor-primaria
    [ ] --cor-destaque
    [ ] --cor-texto
    [ ] --cor-fundo
    [ ] --cor-borda
    [ ] --fonte-texto
    [ ] --fonte-titulo
    [ ] --espaco
    [ ] --raio

[ ] Nenhuma cor hardcoded (todas usam var(...))
    [ ] Teste: mude --cor-primaria → site inteiro muda? Sim ☐ Não ☐

[ ] Seletores bem usados:
    [ ] Tipo (.cabecalho)
    [ ] Classe (.botao, .card)
    [ ] Combinador (nav > ul, article + article)
    [ ] Atributo (input[type="email"])

[ ] DevTools Styles: nenhuma linha riscada com alerta ⚠️

6. BOX MODEL E LAYOUTS (Aula 06-07)
================================================================================

[ ] Reset com box-sizing: border-box
[ ] Margin: 0 no body

[ ] Espaçamentos em rem (não px para fonte)
    Exemplo: margin: 1rem, padding: var(--espaco)

[ ] Header em display: flex:
    [ ] Logo à esquerda
    [ ] Menu à direita
    [ ] space-between alinhamento

[ ] Galeria de cards:
    [ ] display: grid ou flex
    [ ] auto-fit ou repeat
    [ ] minmax(220px, 1fr) ou similar
    [ ] 3 cards lado a lado? (desktop) Sim ☐ Não ☐

[ ] Formulário:
    [ ] Campos ocupam largura total
    [ ] Botão estilizado

[ ] Footer:
    [ ] Fica no fim da página (com min-height: 100vh) Sim ☐ Não ☐


================================================================================
7. PSEUDO-CLASSES E PSEUDO-ELEMENTOS (Aula 07)
================================================================================

[ ] Links têm estados:
    [ ] a:hover (cor muda)
    [ ] a:focus-visible (outline visível)
    [ ] Sublinhado mantido (WCAG AA)

[ ] Pseudo-classes:
    [ ] :hover em .botao (sombra, cor)
    [ ] :focus-visible em inputs
    [ ] :nth-child ou :last-child em algum lugar

[ ] Pseudo-elementos:
    [ ] ::after em pelo menos 1 lugar (ex: ::after com content)
    [ ] ::before bonus se houver

[ ] Ordem correta LVHFA (Link, Visited, Hover, Focus, Active)


================================================================================
8. RESPONSIVIDADE (Aula 07)
================================================================================

[ ] <meta name="viewport"> presente

[ ] Mínimo 1 @media query:

    [ ] 375px (mobile): 1 coluna ☐
    [ ] 768px (tablet): 2 colunas ☐

[ ] Fonte mínima: 16px ☐
