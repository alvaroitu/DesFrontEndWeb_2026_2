1. Tres formas de ligar o CSS ao HTML

Inline, interno e externo. Todas funcionam; so a externa escala para um site inteiro.

style="" inline: so aquele elemento

Codigo 
<p style="color: #1A237E; font-size: 18px;">
  Texto com estilo inline
</p>
Resultado

Texto com estilo inline

Evite: mistura conteudo com aparencia e vence quase qualquer regra do arquivo. Uso legitimo hoje: e-mail em HTML.

<style> interno: so aquela pagina

Codigo 
<head>
  <style>
    p { color: #1A237E; font-size: 18px; }
  </style>
</head>
Resultado

Todo paragrafo desta pagina fica assim.

Bom para prototipo e teste rapido. Trocar o visual de 50 paginas = editar 50 arquivos.

<link rel="stylesheet"> externo: o site inteiro

Codigo 
<head>
  <link rel="stylesheet" href="css/estilo.css">
</head>

/* css/estilo.css */
p { color: #1A237E; font-size: 18px; }
Resultado

Esta propria pagina usa um bloco <style> para caber em um arquivo so; a pagina exemplo 02-perfil usa CSS externo.

O navegador guarda o .css em cache: a segunda pagina do site ja abre com o estilo pronto.

Caminho: o href segue a mesma regra do src da imagem. Caminho errado = pagina sem estilo e um 404 na aba Network.

2. Anatomia de uma regra

Seletor, bloco de declaracao, propriedade e valor. E um erro de CSS nunca aparece no console.

seletor { propriedade: valor; } a forma de toda regra

Codigo 
/* comentario: o navegador ignora */
h1 {
  color: #1A237E;       /* declaracao */
  font-size: 2rem;
  margin-bottom: 16px;  /* ; separa as declaracoes */
}
Resultado

Titulo

Comentario em CSS e so /* */. Nao existe // em CSS.

; esquecido o erro silencioso

Codigo 
.d-ok {
  font-family: Georgia, serif;
  color: #1d7a4d;
}
.d-erro {
  font-family: Georgia, serif     /* falta ; */
  color: #1d7a4d;
}
Resultado

Com ponto e virgula: fonte e cor aplicadas.

Sem ponto e virgula: nem a fonte nem a cor.

Por que as duas somem: o navegador le Georgia, serif color: #1d7a4d como um valor so, invalido. No DevTools, a declaracao aparece riscada com um icone de alerta.

3. Cores

Cinco formas de dizer a mesma cor. color pinta o texto; background-color pinta o fundo.

color nome, hexa, rgb e hsl

Codigo 
color: orange;
color: #FF6F00;
color: #F60;              /* = #FF6600 */
color: rgb(255 111 0);
color: rgb(255 111 0 / 50%);
color: hsl(26 100% 50%);
color: hsl(26 100% 35%);  /* mesma cor, mais escura */
Resultado
orange #FF6F00 #F60 rgb rgb / 50% hsl 50% hsl 35%

hsl: mudar so o ultimo numero (luz) gera o tom do hover e o tom claro do mesmo botao.

contraste 4,5:1 para texto normal

Codigo 
.ruim { color: #BBBBBB; background: #FFFFFF; }  /* 1,9:1 */
.bom  { color: #37474F; background: #FFFFFF; }  /* 9,9:1 */
Resultado

Texto cinza claro: lindo no Figma, ilegivel no sol.

Texto cinza escuro: passa no WCAG AA com folga.

No DevTools, clicar na amostra de cor mostra a razao de contraste e se ela passa em AA e AAA.

4. Unidades de medida

rem para fonte e espaco, % para largura, px para borda.

em x rem em acumula; rem nao

Codigo 
.d-em  li { font-size: 1.2em;  }
.d-rem li { font-size: 1.2rem; }
Resultado
  • em nivel 1
    • nivel 2
      • nivel 3
  • rem nivel 1
    • nivel 2
      • nivel 3

em multiplica pela fonte do pai: 1,2 x 1,2 x 1,2. rem olha sempre o html e fica igual em qualquer nivel.

ch largura de caractere

Codigo 
.d-ch { max-width: 30ch; }
Resultado

Com max-width em ch, a linha de texto nunca passa de uns 30 caracteres, nao importa o tamanho da tela.

Para leitura confortavel em texto corrido, algo entre 60ch e 75ch.

5. Seletores basicos

Universal, tipo, classe, id e agrupamento.

p .classe #id a, b os cinco do dia a dia

Codigo 
p          { margin: 4px 0; }
.destaque  { color: #FF6F00; }
#topo      { background: #E8EFFA; }
p.aviso    { color: #B3261E; }   /* <p> COM a classe */

<p id="topo">Paragrafo com id</p>
<p class="destaque">Paragrafo destaque</p>
<span class="destaque">Span destaque</span>
<p class="aviso">Paragrafo aviso</p>
Resultado

Paragrafo com id

Paragrafo destaque

Span destaque

Paragrafo aviso

No CSS a classe tem ponto; no HTML nao: class="destaque". E p.aviso (sem espaco) e diferente de p .aviso (com espaco).

6. Combinadores

Selecionar pela posicao na arvore do HTML. O destaque laranja mostra o que cada seletor pega.

.post p descendente: qualquer nivel

Codigo 
.post p { background: #FFF3C4; }
Resultado

Titulo

Primeiro paragrafo

Segundo paragrafo

Paragrafo do rodape

Pega as tres <p>, inclusive a de dentro da div.

.post > p filho direto

Codigo 
.post > p { background: #FFF3C4; }
Resultado

Titulo

Primeiro paragrafo

Segundo paragrafo

Paragrafo do rodape

So as duas <p> que sao filhas diretas do .post.

h4 + p irmao imediatamente seguinte

Codigo 
h4 + p { background: #FFF3C4; }
Resultado

Titulo

Primeiro paragrafo

Segundo paragrafo

Paragrafo do rodape

So a <p> que vem logo depois do titulo.

h4 ~ p todos os irmaos seguintes

Codigo 
h4 ~ p { background: #FFF3C4; }
Resultado

Titulo

Primeiro paragrafo

Segundo paragrafo

Paragrafo do rodape

As duas <p> irmas do titulo. A do rodape e neta, nao irma.

7. Seletores de atributo

Selecionar pelo que ja esta escrito na tag, sem inventar classe.

[attr] ^= $= existe, comeca com, termina com

Codigo 
a[href$=".pdf"]     { color: #1D7A4D; }
a[href$=".pdf"]::after { content: " (PDF)"; }
a[href^="https"]    { color: #B3261E; }
input[type="email"] { border: 2px solid #1B4FA0; }
[required]          { background: #FFF3C4; }
Resultado

Link interno · manual.pdf · MDN (externo)

Truque de revisao: img:not([alt]) { outline: 3px solid red; } acha toda imagem sem alt da pagina.

8. A cascata

Origem, especificidade e ordem, nesta sequencia.

ordem empate: vence a ultima

Codigo 
p { color: blue; }
p { color: red; }
Resultado

Mesma especificidade: a regra de baixo vence.

Brigam so as declaracoes da mesma propriedade. Uma regra com cor e outra com tamanho valem juntas.

9. Heranca

O que e de texto desce do pai para os filhos; o que e de caixa, nao.

inherit texto herda, caixa nao

Codigo 
.pai {
  color: #1A237E;
  font-family: Georgia, serif;
  border: 3px solid #FF6F00;
}
.filho-inherit { border: inherit; }
Resultado
Pai com cor, fonte e borda

Filho: herdou cor e fonte, nao herdou a borda.

Filho com border: inherit, forcando a heranca.

Excecao importante: button, input, select e textarea nao herdam a fonte do body por padrao. O conserto e font: inherit.

10. Especificidade

Placar (id, classe, tipo), comparado coluna por coluna, da esquerda para a direita.

(1,0,1) x (0,3,0) um id vence qualquer numero de classes

Codigo 
#menu a              { color: #1B4FA0; }  /* (1,0,1) */
.menu .link.ativo    { color: #B3261E; }  /* (0,3,0) */
Resultado
Link com as duas regras: azul

Nao e soma decimal: 11 classes continuam perdendo para 1 id.

(0,1,0) x (0,0,4) uma classe vence qualquer numero de tags

Codigo 
.link          { color: #B3261E; }   /* (0,1,0) */
nav ul li a    { color: #1B4FA0; }   /* (0,0,4), veio depois */
Resultado
  • Link: vermelho, apesar da ordem

11. !important

Passa por cima da especificidade. Use como excecao documentada, nunca como solucao.

!important vence ate o id

Codigo 
.aviso   { color: #B3261E !important; }
#texto   { color: #1B4FA0; }
Resultado

Tem id azul, mas o !important da classe vence.

Para vencer um !important, so outro !important. E assim que comeca a corrida que destroi um CSS.

12. O modelo de caixa

content, padding, border e margin. Todo elemento da pagina e uma caixa.

padding border margin dentro e fora da borda

Codigo 
.caixa {
  width: 220px;
  padding: 20px;               /* dentro da borda */
  border: 6px solid #37474F;
  margin: 16px;                /* fora da borda */
  background: #E8EFFA;         /* pinta conteudo + padding */
}
Resultado
Conteudo

O amarelo e o pai: a faixa amarela em volta e a margem, sempre transparente.

No DevTools, a aba Computed desenha este diagrama para qualquer elemento.

13. box-sizing

O width inclui ou nao o padding e a borda?

content-box (padrao) width so do conteudo

Codigo 
.coluna {
  width: 50%;
  padding: 16px;
  border: 3px solid #1B4FA0;
  box-sizing: content-box;
}
Resultado
coluna 1
coluna 2 caiu

50% + 32px de padding + 6px de borda: cada coluna passa da metade e a segunda cai.

border-box width inclui padding e borda

Codigo 
*, *::before, *::after {
  box-sizing: border-box;
}
Resultado
coluna 1
coluna 2 cabe

Primeira regra de praticamente todo projeto profissional.

14. Atalhos de margin e padding

Um a quatro valores, em sentido horario a partir do topo.

margin: 10px 30px 20px 50px topo, direita, base, esquerda

Codigo 
margin: 10px;                 /* os quatro */
margin: 10px 20px;            /* vertical | horizontal */
margin: 10px 20px 30px;       /* topo | laterais | base */
margin: 10px 30px 20px 50px;  /* topo | direita | base | esquerda */
Resultado
margin: 10px 30px 20px 50px

O laranja e a margem aparecendo atras da caixa.

margin: 0 auto centraliza bloco com largura

Codigo 
.container {
  max-width: 200px;
  margin: 0 auto;
}
Resultado
bloco centralizado

Sem width ou max-width nao ha sobra para dividir, e o auto nao faz nada.

15. display

block, inline, inline-block e none.

display como a caixa entra no fluxo

Codigo 
span              { display: inline; }        /* padrao */
.ib               { display: inline-block; width: 110px; }
.bl               { display: block; }
.none             { display: none; }
.hid              { visibility: hidden; }
Resultado

Texto com span inline no meio e inline-block tambem.

Link com padding: inline vaza por cima das linhas vizinhas quando o paragrafo quebra em mais de uma linha.

span com display: block ocupa a linha toda

Antes none|hidden depois (o hidden guardou o espaco).

16. Variaveis CSS

Um valor definido uma vez, lido com var(). Mude a cor abaixo e veja tudo que usa a variavel mudar junto.

--nome var(--nome) custom properties

Codigo 
:root {
  --cor-primaria: #1A237E;
  --raio: 8px;
  --espaco: 12px;
}
.botao {
  background: var(--cor-primaria);
  border-radius: var(--raio);
  padding: var(--espaco) calc(var(--espaco) * 2);
}
.botao--secundario {
  background: transparent;
  color: var(--cor-primaria);
  border: 2px solid var(--cor-primaria);
}
.reserva { color: var(--nao-existe, #1D7A4D); }
Resultado

Titulo na cor primaria

Primario Secundario

Esta cor veio do valor reserva do var().

Tema escuro inteiro = redefinir as variaveis. E a resposta do slide 3: trocar a cor do site em uma linha.

17. Organizacao modular e nomes de classe

Um arquivo por responsabilidade e nomes pelo papel, nunca pela aparencia.

css/ base, layout, componentes

Codigo 
css/
  main.css            <- so @import
  base/
    reset.css
    variaveis.css
    tipografia.css
  layout/
    cabecalho.css
    rodape.css
  componentes/
    botao.css
    card.css

/* main.css: @import SEMPRE no topo */
@import url("base/reset.css");
@import url("base/variaveis.css");
...
Resultado

A pagina exemplo 02-perfil/ desta pasta usa exatamente esta estrutura.

Do mais geral para o mais especifico: o reset vem primeiro, os componentes por ultimo. E a cascata trabalhando a favor.

@import depois de qualquer regra e ignorado em silencio. O caminho e relativo ao main.css, nao ao HTML.

bloco__elemento--modificador convencao BEM

Codigo 
.card { }
.card__titulo { }
.card__texto { }
.card--destaque { }

<div class="card card--destaque">
  <h4 class="card__titulo">Titulo</h4>
  <p class="card__texto">Texto do card</p>
</div>
Resultado

Card normal

So .card


Card destaque

.card + .card--destaque

Todo seletor com uma classe so: especificidade baixa e igual em tudo.
