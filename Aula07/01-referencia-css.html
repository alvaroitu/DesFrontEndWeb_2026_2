1. Texto e tipografia

Pilha de fontes, tamanho, peso, altura de linha e transformacao.

line-height o respiro entre as linhas

Codigo 
.apertado { line-height: 1; }
.confortavel { line-height: 1.6; }  /* sem unidade */
Resultado

Com line-height 1, as linhas quase se tocam e o olho se perde ao pular de uma linha para a outra num paragrafo longo como este.

Com line-height 1.6, o mesmo paragrafo respira, e o olho encontra o comeco da linha seguinte sem esforco nenhum.

font-* text-* peso, espacamento e caixa

Codigo 
h4 {
  font-family: Georgia, serif;
  font-size: 1.6rem;
  font-weight: 700;
  letter-spacing: -0.5px;
}
.selo {
  text-transform: uppercase;
  letter-spacing: 0.1em;
  font-size: 0.72rem;
}
Resultado
novidade

Titulo com Georgia

text-transform muda so a aparencia: o leitor de tela le o texto original, em minusculas.

2. Links e seus estados

Ordem LVHFA: link, visited, hover, focus, active. Navegue com Tab para ver o foco.

a:hover a:focus-visible os cinco estados

Codigo 
a         { color: #1A237E; }
a:visited { color: #6A1B9A; }
a:hover   { color: #FF6F00; }
a:focus-visible { outline: 3px solid #FF6F00; outline-offset: 2px; }
a:active  { color: #C62828; }
Resultado

Link com foco visivel · link com outline: none (tente achar com Tab)

Nunca outline: none sem outro indicador de foco. Quem navega por teclado fica perdido.

4. Tabelas

Borda unica, cabecalho escuro, zebra, linha viva e numeros alinhados. E a solucao da pratica 1.

border-collapse :nth-child a tabela de notas

Codigo

th, td { border: 1px solid #DFE3EA; padding: 6px 10px; }
thead th { background: #1A237E; color: #FFF; }

tbody tr:hover { background: #FFF3E0; }
td + td { text-align: right; font-variant-numeric: tabular-nums; }

7. Pseudo-classes de estado

O elemento reage ao usuario e ao formulario.

:hover :focus-visible :active :user-invalid :checked reagindo ao usuario

Codigo 
button:hover         { background: #E8EFFA; }
button:focus-visible { outline: 3px solid #FF6F00; }
button:active        { transform: translateY(1px); }
input:user-invalid   { border-color: #C62828; }
input:valid          { border-color: #2E7D32; }
input:checked + span { text-decoration: line-through; }
Resultado

:user-invalid so pinta de vermelho depois que o usuario interage; o :invalid pintaria antes de digitar.

15. grid-template-areas

O layout desenhado em texto: cada string e uma linha, cada palavra uma coluna.

grid-template-areas o esqueleto da pagina

Codigo 
body {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-areas:
    "cab cab"
    "lat cont"
    "rod rod";
}
header { grid-area: cab; }
aside  { grid-area: lat; }
main   { grid-area: cont; }
footer { grid-area: rod; }
Resultado
header
aside
main
footer

No celular, uma @media redefine as areas em uma coluna. O HTML nao muda. A pagina 02-cantina faz exatamente isso.
