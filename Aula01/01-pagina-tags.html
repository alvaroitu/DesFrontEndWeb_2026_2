Roteiro do semestre

A ordem de estudo é sempre a mesma: primeiro o conteúdo, depois a apresentação. Quem inverte isso acaba usando negrito e itálico no lugar de estrutura — e o leitor de tela não entende nada.

O HTML descreve o que a coisa é. O CSS descreve como ela aparece.
  1. Estrutura do documento e tags do <head>
  2. Texto, listas e tabelas
  3. Links e imagens
  4. CSS: seletores, cores e caixa
  5. Layout responsivo

Fórmula que aparece no exemplo de química: H2O.
Fórmula que aparece no exemplo de matemática: x2 + y2.

Atenção ao que é cobrado na avaliação: tags semânticas, acessibilidade da imagem e uso correto de id e class.

Glossário

HTML
Linguagem de marcação que dá estrutura e significado ao conteúdo.
CSS
Linguagem de estilo: cores, espaçamentos, tipografia e layout.
Tag vazia
Elemento sem conteúdo e sem fechamento, como <br>, <hr> e <img>.
Entidade
Código para escrever caracteres reservados: &lt; vira <, &amp; vira & e &copy; vira ©.
