1. <audio>

Som nativo no navegador, sem plugin. Os arquivos de exemplo estao na pasta midia/.

<audio controls> toca um arquivo de som

Codigo 
<audio controls>
  <source src="midia/audio.mp3" type="audio/mpeg">
  Seu navegador nao toca audio.
  <a href="midia/audio.mp3">Baixar o audio</a>
</audio>
Resultado

controls desenha o player padrao do navegador.

O texto entre as tags e o plano B: so aparece se o navegador nao entender <audio>. Mesma logica do alt.

Sem controls: o audio existe na pagina, mas o usuario nao ve nada e nao consegue tocar. So o JavaScript alcanca.

2. <video>

Todo player que voce usa hoje (YouTube, Netflix, Instagram) e um <video> com uma interface propria por cima.

<video> toca um video com capa e legenda

Codigo 
<video controls width="400" height="225"
       poster="midia/capa.jpg" preload="metadata">
  <source src="midia/video.webm" type="video/webm">
  <source src="midia/video.mp4"  type="video/mp4">
  <track kind="captions" src="midia/legendas.vtt"
         srclang="pt-BR" label="Portugues" default>
  Seu navegador nao suporta video.
  <a href="midia/video.mp4">Baixar o video</a>
</video>
Resultado

width/height reservam o espaco; poster e a capa antes do play.

Responsivo: o video nao encolhe sozinho no celular. No CSS: video { max-width: 100%; height: auto; }

3. <source>, formatos e codecs

Varias opcoes do mesmo arquivo; o navegador escolhe a primeira que sabe tocar.

<source> lista de alternativas, lida de cima para baixo

Codigo 
<video controls>
  <source src="video.webm" type="video/webm">  <!-- 1a opcao -->
  <source src="video.mp4"  type="video/mp4">   <!-- garantia -->
</video>
Como o navegador decide

Le o type de cada <source>, para no primeiro que sabe tocar e ignora o resto. Nao baixa os dois.

Ordem: o mais leve primeiro, o mais compativel por ultimo.

Formatos mais usados
ArquivotypeObservacao
.mp4video/mp4Toca em todo lugar (codec H.264). Resolve quase todo caso.
.webmvideo/webmFormato livre, costuma pesar menos.
.mp3audio/mpegAudio universal.
.oggaudio/oggAudio livre.

Formato = o recipiente

.mp4  .webm  .mp3

Codec = como foi comprimido

H.264  VP9  AV1

Dois arquivos .mp4 podem usar codecs diferentes. Por isso as vezes um toca e o outro nao.

4. Atributos de comportamento

Valem para <audio> e <video>. Sao atributos booleanos: basta escrever o nome.

O que cada atributo faz
AtributoEfeito
controlsMostra os controles nativos (play, volume, tela cheia).
autoplayTenta tocar sozinho ao carregar. Com som, o navegador bloqueia.
mutedComeca sem som. E o que libera o autoplay.
loopRecomeca ao terminar.
preloadnone (nao baixa nada), metadata (so duracao e tamanho), auto (o navegador decide).
playsinlineNo iPhone, toca dentro da pagina em vez de abrir em tela cheia.

autoplay muted loop playsinline o combo do video de fundo

Codigo 
<video autoplay muted loop playsinline width="300">
  <source src="midia/video.mp4" type="video/mp4">
</video>
Resultado

Toca sozinho, sem som, sem parar e sem controles.

Autoplay com som nao funciona em nenhum navegador moderno. Nao e erro de codigo: e politica de experiencia do usuario.

5. <track>: legenda nao e enfeite

A legenda e um arquivo de texto puro (.vtt) que da para escrever a mao.

<track> + arquivo .vtt legendas sincronizadas

midia/legendas.vtt 
WEBVTT

00:00:00.000 --> 00:00:02.000
Uma abelha pousa na flor.

00:00:02.000 --> 00:00:04.000
Ela procura o nectar.

Dentro do <video> 
<track kind="captions" src="midia/legendas.vtt"
       srclang="pt-BR" label="Portugues" default>
Atributos

kind — captions (transcreve falas e sons, para quem nao ouve) ou subtitles (traducao).

srclang — idioma da legenda.

label — nome que aparece no menu do player.

default — ja comeca ligada.

Veja funcionando no video do grupo 2.

Legenda nao aparece? Abrindo o HTML com duplo clique (file://), o Chrome bloqueia o .vtt. Abra com o Live Server do VS Code.

6. O elemento de midia no JavaScript

Metodo e verbo (faz algo), propriedade e substantivo (guarda um valor), evento e noticia (avisa que algo aconteceu).

play() pause() currentTime muted controles feitos por nos

Codigo 
<video id="v" width="300" src="midia/video.mp4"></video>
<button type="button" id="btnPlay">Play</button>
<button type="button" id="btnParar">Parar</button>
<button type="button" id="btnMudo">Mudo</button>
<output id="tempo">0.0 s</output>

<script>
  const v = document.getElementById("v");

  btnPlay.onclick = () => v.paused ? v.play() : v.pause();
  btnParar.onclick = () => { v.pause(); v.currentTime = 0; };
  btnMudo.onclick = () => v.muted = !v.muted;

  v.addEventListener("play",  () => btnPlay.textContent = "Pause");
  v.addEventListener("pause", () => btnPlay.textContent = "Play");
  v.addEventListener("timeupdate", () =>
    tempo.textContent = v.currentTime.toFixed(1) + " s");
</script>
Resultado (sem controls)

0.0 s

Nao existe stop(). Parar e pause() seguido de currentTime = 0.

Metodos (verbos)
MetodoO que faz
play()Comeca a tocar.
pause()Pausa.
load()Recarrega a midia do zero.
requestFullscreen()Tela cheia.
Propriedades (substantivos)
PropriedadeO que guarda
currentTimePosicao atual, em segundos. Da para ler e escrever.
durationDuracao total. Antes do loadedmetadata vale NaN.
paused / endedtrue ou false. Tocando = !v.paused (nao existe playing).
volumeDe 0 a 1 (0.5 = metade). v.volume = 50 da erro.
mutedtrue = sem som.
playbackRateVelocidade: 1 normal, 2 dobro, 0.5 metade.
Eventos (noticias)
EventoQuando dispara
loadedmetadataJa se sabe a duracao. Hora de configurar a barra de progresso.
play / pauseComecou a tocar / pausou.
timeupdateVarias vezes por segundo enquanto toca. Move a barra de progresso.
endedTerminou.
volumechangeVolume ou mudo mudou.

7. <iframe>: uma pagina dentro da outra

Um site inteiro rodando dentro do seu, isolado do seu CSS. Precisa de internet para aparecer.

<iframe> incorpora conteudo de terceiros

Codigo 
<iframe
  src="https://www.openstreetmap.org/export/embed.html?bbox=-47.30,-23.21,-47.27,-23.19&layer=mapnik"
  title="Mapa de Salto - SP"
  width="400" height="250"
  loading="lazy"
  referrerpolicy="no-referrer">
</iframe>
Resultado

Quadro em branco? Muitos sites (Google, bancos, redes sociais) recusam ser incorporados. O motivo aparece no Console (F12). Use so o codigo de incorporacao oficial do site.

Atributos de seguranca e desempenho
AtributoPara que serve
titleObrigatorio para acessibilidade: o leitor de tela anuncia o que e o quadro.
loading="lazy"So carrega quando o usuario rola ate perto.
sandboxSem valor, bloqueia quase tudo (scripts, formularios, popups). Libere so o necessario: sandbox="allow-scripts".
allowLibera recursos especificos: allow="fullscreen; autoplay".
referrerpolicyControla o que o outro site descobre sobre a sua pagina.

Video do YouTube a plataforma entrega o codigo pronto

Codigo (Compartilhar > Incorporar) 
<iframe width="560" height="315"
  src="https://www.youtube.com/embed/ID_DO_VIDEO"
  title="Nome do video"
  loading="lazy"
  allow="fullscreen; picture-in-picture">
</iframe>
O nosso trabalho

O codigo do YouTube vem com title generico. Troque pelo nome real do video e acrescente loading="lazy".

8. <object> e <embed>

Uso mais comum hoje: mostrar um PDF dentro da pagina.

<object> incorpora um arquivo, com plano B

Codigo 
<object data="midia/documento.pdf"
        type="application/pdf"
        width="400" height="300">
  <p>Nao foi possivel exibir o PDF.
     <a href="midia/documento.pdf">Baixar o PDF</a></p>
</object>
Resultado

<object> aceita conteudo alternativo

<object data="doc.pdf" type="application/pdf">
  <a href="doc.pdf">Baixar</a>
</object>

<embed> nao tem plano B

<embed src="doc.pdf" type="application/pdf">
<!-- elemento vazio: se falhar, nada aparece -->

9. <picture>, srcset e loading="lazy"

A imagem certa para cada navegador e cada tela.

<picture> formato moderno com garantia

Codigo 
<picture>
  <source srcset="midia/foto.webp" type="image/webp">
  <img src="midia/foto.jpg"
       alt="Fatia de toranja vista de cima"
       width="200" height="200"
       loading="lazy">
</picture>
Resultado

Navegador que entende WebP usa o .webp (mais leve); os outros caem no .jpg.

Regras: o <img> dentro do <picture> e obrigatorio, e o alt vai nele. width e height evitam que a pagina "pule" quando a imagem chega.

srcset + sizes mesma imagem em varios tamanhos

Codigo 
<img src="foto-800.jpg"
     srcset="foto-400.jpg 400w,
             foto-800.jpg 800w,
             foto-1600.jpg 1600w"
     sizes="(max-width: 600px) 100vw, 50vw"
     alt="...">
Como ler

400w = "este arquivo tem 400 pixels de largura".

sizes = "em tela ate 600px a imagem ocupa a largura toda; acima disso, metade".

O navegador junta as duas informacoes e baixa so o arquivo necessario. Celular nao baixa a foto de 1600px.

10. <canvas>: uma area em branco e um pincel

O HTML cria a tela; o JavaScript desenha. Depois de desenhado, so sobra pixel.

<canvas> + getContext("2d") o primeiro retangulo

Codigo 
<canvas id="tela" width="300" height="150">
  Um quadrado azul.   <!-- plano B / acessibilidade -->
</canvas>

<script>
  const ctx = document.getElementById("tela").getContext("2d");
  ctx.fillStyle = "#1b4fa0";      // escolhe a tinta
  ctx.fillRect(20, 20, 100, 100); // x, y, largura, altura
</script>
Resultado Um quadrado azul.

A origem (0, 0) e o canto superior esquerdo. O y cresce para baixo.

Erro classico: width e height vao no atributo, nao no CSS. Pelo CSS o desenho estica e fica borrado.

Tamanho no atributo

<canvas width="300" height="150">

Tamanho no CSS: borra

canvas { width: 300px; height: 150px; }

11. Formas e caminhos no canvas

fill pinta por dentro, stroke desenha o contorno.

fillRect, strokeRect, beginPath, arc retangulo, triangulo e circulo

Codigo 
// retangulos
ctx.fillStyle = "#1d7a4d";
ctx.fillRect(10, 20, 80, 60);
ctx.strokeStyle = "#b3261e";
ctx.lineWidth = 3;
ctx.strokeRect(110, 20, 80, 60);

// triangulo (caminho livre)
ctx.beginPath();
ctx.moveTo(250, 20);   // levanta o lapis e vai ate
ctx.lineTo(290, 80);   // risca ate
ctx.lineTo(210, 80);
ctx.closePath();       // volta ao inicio
ctx.fillStyle = "#ff6f00";
ctx.fill();

// circulo: arc(x, y, raio, inicio, fim)
ctx.beginPath();
ctx.arc(150, 120, 22, 0, Math.PI * 2);
ctx.fillStyle = "#1b4fa0";
ctx.fill();
Resultado Um retangulo verde, um contorno vermelho, um triangulo laranja e um circulo azul.

Angulos em radianos: volta inteira = Math.PI * 2.

Esqueceu o beginPath()? O novo desenho continua o caminho anterior e aparecem linhas ligando tudo.

12. Texto, imagem e animacao no canvas

Tudo que vai para o canvas vira pixel, inclusive o texto.

fillText e drawImage escrever e colar imagem

Codigo 
ctx.font = "bold 20px Arial";
ctx.fillStyle = "#16181d";
ctx.fillText("Ola, canvas!", 10, 30); // texto, x, y

const img = new Image();
img.src = "midia/foto.jpg";
img.onload = () => {
  ctx.drawImage(img, 180, 10, 100, 100); // x, y, larg, alt
};
Resultado Texto "Ola, canvas!" e a foto de uma toranja.

Armadilha: desenhar a imagem antes do onload nao da erro nenhum — ela simplesmente nao aparece.

requestAnimationFrame animacao quadro a quadro

Codigo 
let x = 0;

function quadro() {
  ctx.clearRect(0, 0, 300, 80);   // 1. apaga
  ctx.beginPath();                // 2. desenha
  ctx.arc(x, 40, 15, 0, Math.PI * 2);
  ctx.fillStyle = "#b3261e";
  ctx.fill();
  x = (x + 2) % 300;              // 3. avanca
  requestAnimationFrame(quadro);  // 4. pede o proximo
}
quadro();
Resultado Uma bola vermelha atravessando a tela.

Sem o clearRect, a bola deixa rastro: o canvas nao lembra o que desenhou.

13. <svg>: desenho que e codigo

Vetor (nao borra), faz parte do DOM (recebe CSS e clique) e e texto (abre no bloco de notas).

<svg> grafico de barras sem uma linha de JavaScript

Codigo 
<svg width="300" height="150" viewBox="0 0 300 150"
     role="img" aria-label="Vendas: Jan 60, Fev 100, Mar 40">
  <rect x="30"  y="90" width="50" height="60">
    <title>Jan: 60</title>
  </rect>
  <rect x="120" y="50" width="50" height="100">
    <title>Fev: 100</title>
  </rect>
  <rect x="210" y="110" width="50" height="40">
    <title>Mar: 40</title>
  </rect>
</svg>

/* CSS */
rect { fill: #1b4fa0; }
rect:hover { fill: #ff6f00; }
Resultado (passe o mouse nas barras)

Cada barra e um elemento: aparece no inspetor (F12), muda de cor com CSS e mostra dica propria.

Acessibilidade: role="img" + aria-label descrevem o desenho inteiro para o leitor de tela.

14. Formas do SVG e o viewBox

fill e stroke funcionam como propriedades CSS.

rect circle ellipse line polyline polygon path text as formas basicas

Codigo 
<svg width="300" height="160" viewBox="0 0 300 160">
  <rect x="10" y="10" width="60" height="40" fill="#1b4fa0"/>
  <circle cx="115" cy="30" r="20" fill="#1d7a4d"/>
  <ellipse cx="190" cy="30" rx="35" ry="18" fill="#ff6f00"/>
  <line x1="240" y1="10" x2="290" y2="50"
        stroke="#b3261e" stroke-width="4"/>
  <polyline points="10,120 40,80 70,110 100,70"
            fill="none" stroke="#1b4fa0" stroke-width="3"/>
  <polygon points="150,70 180,120 120,120" fill="#f5a623"/>
  <path d="M200 120 Q230 60 260 120" fill="none"
        stroke="#5b6270" stroke-width="3"/>
  <text x="10" y="150" font-size="14">Texto no SVG</text>
</svg>
Resultado

polyline precisa de fill="none", senao preenche de preto. path e a forma mais poderosa: icone exportado do Figma e um path longo.

viewBox coordenadas internas x tamanho na tela

Codigo 
<!-- o mesmo desenho, viewBox 0 0 24 24 -->
<svg viewBox="0 0 24 24" width="24" height="24">...</svg>
<svg viewBox="0 0 24 24" width="48" height="48">...</svg>
<svg viewBox="0 0 24 24" width="96" height="96">...</svg>
Resultado

viewBox diz "o desenho vive num quadro de 24 x 24". width/height dizem o tamanho na tela. Resultado: amplia sem borrar.

Sem viewBox, o SVG nao escala: aumentar o width so aumenta a area vazia em volta.

15. Quatro formas de colocar um SVG na pagina

A escolha depende de uma pergunta: o CSS e o JavaScript da pagina precisam mexer no desenho?

inline x <img> so o inline obedece ao CSS da pagina

Codigo 
<!-- 1. inline: faz parte do DOM -->
<svg class="icone-tema" viewBox="0 0 24 24" width="48" height="48">
  <path d="M12 2l3 7h7..." fill="currentColor"/>
</svg>

<!-- 2. arquivo externo por <img> -->
<img src="midia/icone.svg" alt="Estrela" width="48" height="48">

/* CSS */
.icone-tema { color: green; }
.icone-tema:hover { color: red; }
Resultado (passe o mouse nos dois)

 

O inline muda de cor. O <img> e um documento fechado: o CSS da pagina nao entra.

Qual usar
FormaExemploQuando usar
inline<svg>...</svg> no HTMLMuda de cor, anima ou responde a clique.
<img><img src="logo.svg" alt="...">Ilustracao ou logo fixo.
background CSSbackground-image: url(fundo.svg);Decoracao. Some para o leitor de tela.
<use> (sprite)<svg><use href="icones.svg#casa"/></svg>Muitos icones num arquivo so (sistemas de design).

16. Imagem, canvas ou SVG: como decidir

Nao existe resposta unica: existe criterio. O que muda e o requisito.

Comparativo
CriterioImagem (img)<canvas><svg>
TipoPixel prontoPixel desenhado por JSVetor (formas)
Amplia sem borrarNaoNaoSim
Cada parte e elemento do DOMNaoNaoSim
Recebe CSS e clique por parteNaoNaoSim
Muda com os dadosNaoSim (redesenha)Sim
Milhares de objetos / jogos—MelhorFica lento
AcessibilidadealtSo o texto entre as tagstitle, aria-label

A regra em uma frase

  • Foto ou ilustracao que nunca muda: imagem.
  • Cada parte precisa ser um objeto (clicar, estilizar, ler): SVG.
  • O que importa e a cena inteira e a velocidade (jogo, animacao pesada, edicao de foto): canvas.
